# DaRUS-4559 post-calibration assessment: reproducibility package

This package reproduces the numerical assessment in the revised Measurement manuscript, including Reviewer 1 Comments 2-4. It is a reproducibility implementation assembled from the verified analyses, not the upstream authors' calibration algorithm. No robot calibration or physical compensation is performed.

## Run (Windows CMD)
Install Python 3.12, extract this folder, and open CMD in it:

    py -3.12 -m venv .venv
    .venv\Scripts\python -m pip install -r requirements.txt
    .venv\Scripts\python run_all.py

On Linux/macOS, use python3.12 to create the environment and .venv/bin/python for installation and execution. The verified environment used Python 3.12.14. Input data are bundled, so running the analysis needs no data download or authentication after installing dependencies.

## Entry points and outputs
- run_all.py: executes every analysis and numerical check; records actual software versions.
- analyze_core.py: Tables 2-5, 8-9 numeric quantities, covariance, calibration-validation ratios, bias-scatter decomposition, empirical quantiles and integrity audit; regenerates Figures 1,2,3,7,8.
- r1c2/analyze_r1c2.py: calibration-box and nearest-distance partitions (Table 6), distance correlations, Figures 4-5.
- r1c3/analyze_r1c3.py: spatially adjusted joint correlations, five regression models, repeated and spatial CV, VIFs, Table 7, saved fold assignments and predictions.
- r1c3/verify_and_plot.py: independent numerical checks and Figure 6.
- r1c4/check_coverage.py: full-precision coverage counting and Table 8 coverage row.
- outputs/, r1c2/outputs/, r1c3/outputs/: CSV/JSON outputs and PDF/PNG figures; r1c4/ contains coverage CSV/JSON.

The regenerated figures reproduce the quantitative content; graphical styling need not be pixel-identical to the manuscript. Figure 1 is a conceptual workflow schematic, not a data result. Table 1 is a literature synthesis and is not generated by the numerical analysis.

## Numerical conventions
All 45 calibration and 100 validation poses are retained. Residuals and Cartesian positions are read directly from the released columns. Residuals are converted metres to millimetres; position controls and distances remain in metres. Euclidean error is norm(E_x,E_y,E_z). No imputation or pose exclusion. Six physical joints Theta_1..Theta_6 are used in recorded radians; auxiliary Theta_3_1 is excluded.
Sample covariance/SD use N-1. Percentiles use NumPy linear interpolation (Hyndman-Fan type 7). Bias removal is diagnostic subtraction of the same sample mean, not externally tested compensation. u_res is sqrt(trace(sample covariance)); U_res,k2=2*u_res. Empirical coverage compares original, uncentred error norms with the full-precision threshold; 90/100 covered.
Mean intervals use Student t with N-1 degrees of freedom. Correlation intervals use Fisher transformation, normal 1.96 quantile and SE=1/sqrt(N-3); the Spearman interval is an approximate analytical sensitivity descriptor. None accounts for arbitrary pose dependence.
The full-precision Table 9 intervals differ slightly from earlier manuscript calculations based on rounded moments. Use outputs/analytical_intervals.csv and the supplied correction instructions. This changes only displayed endpoint digits, not the interpretation.

## Spatial and joint settings
Calibration-box membership tests all three Cartesian coordinates, inclusive boundaries. Nearest-calibration distance is minimum Euclidean distance to 45 calibration positions. Its tertiles use unrounded linear-interpolated 1/3 and 2/3 quantiles, assigning equality to the lower group.
Partial Spearman: average-rank E, each joint and x,y,z; separately regress ranked E and ranked joint on ranked x,y,z plus intercept; Pearson correlation of residuals. Other joints are not controlled in this calculation.
OLS models: J=6 joints; S=x,y,z; S+J=9 predictors; S2=x,y,z,x^2,xy,xz,y^2,yz,z^2; S2+J=15 predictors. All include an intercept. Polynomial monomials are deterministic, and standardization is fitted on training folds. No tuning, feature selection or prediction clipping.
RepeatedKFold: 5 folds, 20 repetitions, seed4559; identical splits across models. Pool 100 out-of-fold predictions for each repetition; summarize repetition metrics by mean and sample SD. SD is split sensitivity, not a confidence interval.
Spatial CV: KMeans using unscaled metre-space x,y,z, five regions, 50 initializations, random_state4559; region sizes 19,29,9,22,21. No outcomes used to form regions. Hold out each region and pool all100 predictions. No spatial buffer. One partition is a sensitivity analysis, not universal extrapolation validation.
VIF in S+J uses regressions against all remaining predictors plus intercept. Joint effects are model-conditional associations, not identified physical causes. All CV errors describe prediction of error magnitude, not robot positioning after compensation.

## Checks and audit findings
run_all.py verifies checksums and baseline estimates, covariance/bias-scatter identities, independent raw-design OLS, inverse-matrix partial correlations/VIFs, fold coverage, and coverage counts. No fabricated or manually tuned numerical output.
Both time-series files have only three coordinate columns and no timestamp column. Their first and third coordinates are exactly equal. Horizontal rows=57,313; vertical rows=100,737. The vertical sequence has four duplicate rows, retained for integrity assessment. The scripts do not estimate velocity, dynamic path error or controlled repeatability.
